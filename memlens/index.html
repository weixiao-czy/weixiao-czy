LLM-POWERED MEMORY SAFETY TRIAGE

MemLens

给每一次 C/C++ diff 做内存安全体检。

MemLens 是一款基于 LLM 的内存安全分诊工具：输入 git diff 或 patch 文件， 自动识别变更中的内存安全缺陷，输出带 CWE 分类、严重度、证据链、修复建议与 C++ 测试用例建议的 Markdown 报告。

01 / PROBLEM

内存缺陷，总在 code review 里溜走

  • diff 太长看不完改动动辄数百行，人工审查难以逐行推敲生命周期。
  • 缺陷隐蔽UAF、越界读写等问题编译期无告警，运行期才爆发。
  • 报告成本高定位、定级、写修复建议与复现用例，耗时且依赖经验。

02 / FEATURES

核心能力

把「扫一眼 diff」升级为「一次结构化的内存安全分诊」。

七类内存缺陷覆盖

CWE-416 UAF、CWE-120 缓冲区溢出、CWE-190 整数溢出、CWE-415 双重释放、CWE-476 空指针解引用、CWE-787/125 越界读写。

证据链报告

每个问题附具体证据链与严重度分级，而非一句笼统告警。

修复与测试建议

给出文本修复建议，并附 C++ 测试用例建议，便于直接验证。

多模型支持

OpenAI 与 Anthropic 模型一键切换，按成本与能力自由选择。

diff 原生输入

直接读取 git diff / patch 文件，天然贴合 code review 工作流。

Markdown 报告

终端直出或保存为 .md 文件，方便归档进 PR 与知识库。

03 / WORKFLOW

工作流程

  1. 安装克隆仓库并以可编辑模式安装依赖。
  2. 配置复制 .env.example 并填入模型 API Key。
  3. 扫描对 diff 文件执行 memlens scan 并选择模型。
  4. 报告终端查看或导出 Markdown 审查报告。

04 / QUICKSTART

快速开始

TERMINALbash
# 1. 安装
$ git clone https://github.com/weixiao-czy/memlens && cd memlens
$ pip install -e ".[dev]"

# 2. 配置 API Key / Base URL
$ cp .env.example .env

# 3. 扫描 diff 并导出报告
$ memlens scan --diff examples/sample.diff --model openai:gpt-4o-mini -o report.md

# 4. 切换提供商
$ memlens scan --diff examples/sample.diff --model anthropic:claude-3-5-sonnet
